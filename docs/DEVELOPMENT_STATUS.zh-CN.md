# HomePodCast 当前版本状态

当前发布以便携版 `HomePodCast.exe` 为默认交付。虚拟输出使用 VB-CABLE，主界面指引包含官方下载、安装步骤和 **CABLE Input** 检测。使用步骤见[使用指南](GUIDE.md)。

## 本版功能

- 已安装的可用 VB-CABLE 直接复用。首次安装时从指引下载官方 ZIP，运行原厂驱动安装程序并重启，回到指引检测音源和配置自动切换。
- 实验性一体安装包与配置向导保留用于兼容既有安装。默认 CI 交付便携 EXE。
- 虚拟模式捕获选定输出，可在串流就绪后自动切换 Windows 默认输出，并在停止时有条件恢复。通信设备单独选择是否切换。
- 电脑输出和虚拟输出有不同列表与说明；失效的已保存设备不会被静默替换。应用的“音箱音量”控制 HomePod，Windows 音量控制当前默认输出。
- 虚拟采集在静音或音量为 0 时清零 PCM。新增可选“软件控制虚拟输出音量”（默认关闭）；启用前须关闭 VB-CABLE 驱动的 Windows 音量控制，避免双重衰减。原驱动音量模式仍可使用。
- 应用更新只接受 `HomePodCast.exe`，不会把安装包误当成应用替换。固定与 pyatv 兼容的 SRP 依赖，自检覆盖离线认证与加密路径。
- 安装器校验第三方包哈希、厂商签名、微软目录签名及 INF/SYS 的目录关联；卸载应用保留共享 VB-CABLE。

- 应用单元测试共 45 项通过，涵盖路由、配置、设备选择、静音、认证、更新和错误处理。
- 驱动构建及探测测试共 9 项。8 项通过，依赖固定上游源码的 1 项在本机跳过。
- 中英文安装指引和四台模式界面检查通过。本次发布使用用户已测试通过的便携 EXE。
- `pip check` 与 Python 编译检查通过。
- 应用及安装器本地构建成功；打包应用的只读自检通过，包含 Tk、音频 API、虚拟配置模块和离线认证。本次本机能够运行该构建，不代表所有 Smart App Control 环境均受信任。
- 远端 CI 的最终结果见提交对应的 GitHub Actions 检查。

本机音频报告、设备标识、接收端地址、特定测试包的主机安装/回滚脚本只保留在本地，不纳入源码提交。历史测试记录见 `P0_AUDIO_VALIDATION.zh-CN.md`；其中引用的 JSON 是本地证据文件。

## 明确保留的限制

- 标准 VB-CABLE 在 Windows 中仍显示原名称和两个播放端点。应用列表优先显示标准 CABLE Input；本版不禁用或重命名 Windows 设备。
- 两种音量模式互斥：软件音量开启时，以管理员身份在 VB-CABLE 控制面板关闭 **Enable Windows Volume Control**；使用驱动音量时则开启该选项并关闭应用的软件音量。本机测得驱动音量开启时 Windows 1–5 采集为零，关闭后采集非零；软件音量方案在低音量下的 HomePod 实际听感尚未验证。Windows 默认输出需与选择的音源一致；录音端的“侦听此设备”应关闭。
- 应用和安装器目前没有生产代码签名；Smart App Control 可能拦截。不会为此关闭系统保护。VB-CABLE 驱动签名不代表外层应用获得信任。
- 自有 `HomePodCast Audio` 驱动仅为测试签名原型，不随安装包安装；虚拟机 PCM 已做过探测，原生静音、正式签名和完整兼容性验收仍未完成。
- 两小时长测按用户要求暂缓；本次不重复安装驱动、重启系统或声称完成新装系统、所有 Windows 版本、休眠和多 HomePod 断线矩阵验收。

构建方式及签名入口见 [安装器说明](../installer/README.md)。使用说明见 [GUIDE](GUIDE.md)。
